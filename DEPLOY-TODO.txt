二游活动评价 —— 部署说明
================================================

## 目录结构（整个文件夹就是网站根目录）

```
_deploy/
├── index.html            中文版（已预渲染，爬虫能直接读到正文）
├── en/index.html         英文版（同上，路径已适配 /en/）
├── assets/opt/           7 张 WebP（1.3MB，原图 3.6MB）
├── assets/og-cover.jpg   社交分享图 1200×630
├── robots.txt
├── sitemap.xml           含中英两条 + hreflang
├── _headers              Cloudflare Pages 用（缓存 + 安全头）
├── _redirects            /en → /en/ 301
└── replace-domain.sh
```

`/` 永远是中文，`/en/` 永远是英文，两页互相声明 hreflang。
语言按钮现在是**跳转**，不再只是本地切换 —— 一个 URL 只对应一种语言，搜索引擎才不会判重。

---

## 你还要做的 3 件事

### 1. 换成你的域名和邮箱（一条命令）

```bash
cd _deploy
sh replace-domain.sh 你的域名.com 你的邮箱@example.com
```

脚本会校验格式、替换全部 7 处、并打印结果。写成 `https://...` 会直接报错拦住你。

### 2. 选托管（唯一需要你拍板的战略问题）

**方案 A：Cloudflare Pages（推荐先用）**
1. 注册 Cloudflare（免费）→ Workers & Pages → Create → Pages → Upload assets
2. 拖入整个 `_deploy` 文件夹 → Deploy
3. Settings → Custom domains 绑定域名（DNS 也放 Cloudflare 最省事）
4. 免费、免备案、自动 HTTPS、全球 CDN、`_headers` 自动生效
5. 代价：国内访问速度一般，偶有波动

**方案 B：国内云（阿里云 OSS / 腾讯云 COS + CDN）**
- 必须 **ICP 备案**（个人可办，5–20 天，要实名）
- 国内秒开，但备案期间内地无法访问；`_headers` 不生效，要手动配缓存

建议：**先用 A 上线收反馈**，等内容和流量稳了再迁国内。

### 3. 需要你的账号才能做的三件事

| 事项 | 在哪做 | 备注 |
|---|---|---|
| 加统计 | Cloudflare → Web Analytics | 免费无 cookie；拿到 token 后把 beacon 脚本贴到中英两页的 `</body>` 前 |
| 提交 sitemap | Google Search Console + 百度搜索资源平台 | 验证域名后提交 `https://你的域名.com/sitemap.xml` |
| 分享自测 | https://developers.facebook.com/tools/debug/ | 输入网址看抓到的标题/图对不对 |

## 改了内容之后怎么重新发布

改 `linshi/index.html`（数据、文案、活动）后，在 Mac 上：

```bash
cd ~/linshi-site
sh build.sh
```

会重新预渲染中英两版并刷新 `_deploy/`，然后重新上传 `_deploy` 即可。

> 为什么要预渲染：正文原本由 JS 渲染，百度这类不执行 JS 的爬虫抓到的是空壳。
> 现在 `index.html` 直接含完整正文（gzip 后约 116KB），Google 和百度都能读。

## 仍建议处理的两件事

- **充值/钱包**：静态站收不了钱，`$0.00` 和「$1 买 100 次」会让用户以为能付费。
  建议改成「演示：支付未开放」或先隐藏。
- **英文版残留中文**：活动名、游戏名是中文原生数据（合理），但统计条「6款 / 8个 / 685份」
  这类界面文案在英文页仍是中文，需要在 `EN_I18N` 里补几条。
